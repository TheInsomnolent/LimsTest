# LimsTest

A placeholder LIMS (Laboratory Information Management System) web application built with React, TypeScript, and Vite.

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This project is automatically deployed to [GitHub Pages](https://theinsomnolent.github.io/LimsTest/) on every push to the `main` branch via the GitHub Actions workflow in `.github/workflows/deploy.yml`.
